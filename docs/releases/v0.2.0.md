## YC Todo 0.2.0

This is the first Universal macOS release of YC Todo. One download supports
both Apple Silicon and Intel Macs.

### Highlights

- A calmer task list with Start always visible and Edit/Delete revealed only
  when needed.
- Compact, row-anchored previews make long task titles readable without
  horizontal scrolling.
- Clear Completed is now reversible for five seconds.
- Free and Strict start modes are explicit, keyboard-friendly choices.
- Refined spacing, visual hierarchy, icons, focus states, and reduced-motion
  behavior throughout the 386×546 menu bar popover.

### Download

Download `YC-Todo-macOS-universal.zip`, unzip it, and move `YC Todo.app` to
`/Applications`. The build is ad-hoc signed and not Apple-notarized, so first
launch requires Control-click → **Open**.

Use `YC-Todo-macOS-universal.zip.sha256` to verify the download.
