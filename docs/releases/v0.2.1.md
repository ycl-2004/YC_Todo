## YC Todo 0.2.1

This patch updates native popover opening on macOS 27. The Universal download
supports Apple Silicon and Intel Macs; tasks, settings, and shortcuts retain
their existing storage format.

### Fixes

- Keep the context menu attached only while showing a right-click menu, avoiding
  macOS 27 consuming subsequent left clicks.
- Use Tauri's public status-item access instead of casting its private layout
  through an incompatible legacy tray dependency.
- Reveal the existing task window when Finder reopens a running YC Todo app.
- Open near the screen's upper right when the menu-bar button has no visible
  anchor, instead of letting AppKit silently ignore the request.

### Download and upgrade

1. Download `YC-Todo-macOS-universal.zip` and its `.sha256` file.
2. Verify the ZIP with `shasum -a 256 -c YC-Todo-macOS-universal.zip.sha256` from
   the download directory.
3. Quit all running YC Todo copies, unzip the archive, and replace
   `/Applications/YC Todo.app`.
4. Open the installed app and check that **About** shows `0.2.1`.

The build remains ad-hoc signed and not Apple-notarized. First launch requires
Control-click → **Open**, as described in the
[README](https://github.com/ycl-2004/YC_Todo#quick-start). No data-folder cleanup
is required to upgrade; keep the existing local storage to retain tasks and settings.

### Compatibility and validation

- Repository checks, frontend lint/build, and the locked Rust check passed.
  Existing lint and Rust warnings remain.
- The Universal bundle includes `arm64` and `x86_64`; strict signature and archive
  checksum validation passed.
- On macOS 27.0.1, the installed app's task window, About version, and reopening
  behavior were checked with existing tasks preserved.
- Thaw 3.0.0-alpha.6 can leave the icon invisible even when its layout lists
  YC Todo as Visible. Quitting Thaw restored the icon in the user's comparison.
  This patch keeps task-window reopening usable but does not establish a fix for
  Thaw's icon management. Thaw alpha.7 has related fixes, but has not been tested
  with YC Todo here; see its
  [official release notes](https://github.com/thaw-app/Thaw/releases/tag/3.0.0-alpha.7).
- Repeated menu-bar left/right-click sequences and global-shortcut/IME input
  still require manual regression checks. Native runtime testing on Intel and
  older supported macOS versions has not been performed for this patch.
