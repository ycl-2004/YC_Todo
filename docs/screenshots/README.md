# README screenshot capture guide

The public README embeds the six refreshed UI captures from this folder. Keep
the file names stable so the image links in the root README continue to work:

| File | What to show |
| --- | --- |
| `01.png` | Main popover with 4–5 neutral tasks, varied tags, and only Start visible on each row |
| `02.png` | One hovered task with Edit and Delete revealed beside Start |
| `03.png` | A truncated task with the row-anchored title preview open |
| `04.png` | Focus-time sheet with the selected task and duration controls |
| `05.png` | Tag-management settings panel |
| `06.png` | macOS dark appearance with the notification settings panel open |

## Capture rules

- Use demo content only—no personal tasks, names, file paths, or notification text.
- Capture the real `/Applications/YC Todo.app` release build at its native
  386×546-point popover size.
- Keep the menu-bar arrow and the complete rounded popover edge visible.
- Use the same accent color and task set across the light/dark pair.
- Save lossless PNGs at 2× scale when possible; do not upscale screenshots.
- Crop consistently and remove unrelated desktop or menu-bar content.

The root `README.md` references these files directly. Replace a capture only
when the replacement keeps the same filename and follows the rules above.
